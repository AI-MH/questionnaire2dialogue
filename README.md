**SQPsych** (Structured Questionnaire-based Psychotherapy) is an LLM-driven pipeline that generates synthetic therapist-client counseling dialogues from real structured client profiles and psychological questionnaires (e.g., BDI, HAM-D). Generation runs entirely on locally hosted **open-weight** models, so clinical questionnaire data is never sent to third-party or proprietary services. This repository contains the generation code; the resulting corpus (**SQPsychConv**) and fine-tuned models (**SQPsychLLM**) are released on Hugging Face.

> **Research use only.** These resources are not a medical device or a substitute for professional care, and must not be deployed to interact with patients without further validation. See [ETHICS.md](ETHICS.md).

## Overview

The pipeline uses two cooperating agents: a **therapist LLM** and a **client LLM** which are grounded in Cognitive Behavioral Therapy (CBT). The client agent is conditioned on de-identified, numerical questionnaire and profile data; the therapist agent conducts the session; an optional rewriting step refines turns. The released corpus is generated by **seven open-weight LLMs**, and includes:

- **Base variants**, one per generating model (`SQPsychConv_<model>`);
- **Ablation variants** without questionnaire conditioning (`SQPsychConv_<model>_no_questionnaire`);
- **Fine-tuning-format variants** (`SQPsychConv_<model>_finetune`) used to train the 8B **SQPsychLLM** models.

## Installation

Requires Python 3.10+ and a GPU environment capable of serving the model you intend to use.

```bash
git clone https://github.com/AI-MH/questionnaire2dialogue.git
cd questionnaire2dialogue
pip install -r requirements.txt
```

## Quickstart: generating dialogues

### 1. Start a vLLM server (OpenAI-compatible API)

```bash
PORT=9000
python -m vllm.entrypoints.openai.api_server \
    --model "google/gemma-3-27b-it" \
    --tensor-parallel-size 2 \
    --pipeline-parallel-size 2 \
    --seed 666 \
    --port $PORT
```

Replace `--model` with whichever open-weight model you want the agents to use. Adjust the parallelism flags to your hardware.

### 2. Point the code at your server

Set `openai_api_base` in `src/llms.py` to match the host and `PORT` above (e.g., `http://localhost:9000/v1`). Make sure the model you serve matches the endpoint configured for the `-m` shortname you select below.

### 3. Run generation

```bash
cd src/
python main.py \
    -m gemma \
    -pc prompts/mdd/mdd_gemma_client.txt \
    -pt prompts/gemma_therapist.txt \
    -q prompts/sample_patient_data/sample.txt
```

### Arguments

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--seed` | int | `666` | Random seed |
| `-m`, `--model` | str | — | Model shortname for both agents (e.g., `qwen`, `llama`, `gemma`) |
| `-pc`, `--prompt_client` | str | — | Client-agent prompt template (see `prompts/`) |
| `-pt`, `--prompt_therapist` | str | — | Therapist-agent prompt template (see `prompts/`) |
| `-ir`, `--iterative_rewrites` | int | `0` | Number of therapist/client rewrite passes |
| `-q`, `--questionnaire` | str | — | Path to the client's questionnaire/profile data (plain text) |

### Input format

The `-q` argument points to a plain-text file of the client's structured questionnaire and profile data.

## Using the released data

The corpus is on Hugging Face and loads directly with the `datasets` library:

```python
from datasets import load_dataset

# Base variant generated by Gemma
ds = load_dataset("AIMH/SQPsychConv_gemma")

# Ablation without questionnaire conditioning
ds_ablation = load_dataset("AIMH/SQPsychConv_gemma_no_questionnaire")

# Fine-tuning-format variant (chat-formatted)
ds_ft = load_dataset("AIMH/SQPsychConv_gemma_finetune")
```

Swap `gemma` for any of the seven generating models. See the [dataset collection](https://huggingface.co/collections/AIMH/sqpsychconv) for the full list and per-variant statistics.

## Using the released models

The 8B **SQPsychLLM** models are fine-tuned on the corpus above and load like any Hugging Face causal LM:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "AIMH/SQPsychLLM-8b-gemma"
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(model_id, device_map="auto")
```

You can also serve them with vLLM using the same command as above (`--model AIMH/SQPsychLLM-8b-gemma`). See the [model collection](https://huggingface.co/collections/AIMH/sqpsychllm) for all checkpoints.

## Fine-tuning

The `SQPsychConv_<model>_finetune` datasets are pre-formatted for instruction fine-tuning. See `src/finetune.py` for details.

## Data provenance

The structured inputs derive from the de-identified cohort reported in Kircher et al. (2019); only pre-anonymized numerical questionnaire and demographic variables are used. All released conversations are **synthetic** and contain no real patient utterances or identifiers. See [ETHICS.md](ETHICS.md) for the full data and ethics statement.
